# BodyMetric privacy policy

The privacy policy for **BodyMetric** (`works.foundy.bodymetric`), the offline body metrics
app by Foundy Works. Served with GitHub Pages at:

https://dewabuanam.github.io/bodymetric-policy/

This is the URL given to Google Play Console. The page is built from the
`bodymetric-web` project (`privacy-policy.html`); after changing it there, run
`npm run build` and copy `dist/privacy-policy.html` (as both `index.html` and
`privacy-policy.html`) and `dist/assets/` here.
